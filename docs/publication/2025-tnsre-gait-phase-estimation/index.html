    Venue: IEEE Transactions on Neural Systems and Rehabilitation Engineering, 33: 4124–4136, 2025

    Recommended citation: Yuanlong Ji, Xingbang Yang, Ruoqi Zhao, Qihan Ye, Quan Zheng, Yubo Fan. Human Locomotion Implicit Modeling-Based Real-Time Gait Phase Estimation. IEEE Transactions on Neural Systems and Rehabilitation Engineering, 33: 4124–4136. https://doi.org/10.1109/TNSRE.2025.3621076

    Research overview

    Real-time gait-phase estimation provides continuous human-motion information for exoskeleton assistance. The reported steady-state phase RMSE is 2.729%. This is a phase-estimation error, not a classification accuracy.
